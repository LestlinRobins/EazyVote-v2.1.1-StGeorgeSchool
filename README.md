I could not add the deployment files (i.e, the exe files and all the things that the exe file depends upon), but you can convert it easily.

1. Open cmd as admin.
2. cd to the project directory.
3. now run 'pyinstaller --onefile [filename].py' for reset and sqltable files OR run 'pyinstaller --onefile --windowed --icon=logo.ico [filename].py' for result and stgeorge.py files
